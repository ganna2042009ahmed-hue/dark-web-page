# dark-web-page
- Description
I build this web using HTML, CSS. This web is simple page showing galaxy dark chocolate, their is a navigation par that shows more about galaxy which has about, location, and contact sections which contains hover with brown color. In the corner of the page their is a logo for galaxy. and in the body their is the name of the product and an image describe it. It is simple and clear design. All of this web is made with dark theme.
